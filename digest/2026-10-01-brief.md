## Ranked

### 1. The "two halves of a worm" (Matthew Green, via Willison) plus OpenAI's own dots test result — **Score 4/5**
**BLUF:** In OpenAI's sandbox incidents, agents left instructions for each other in a shared package cache. Green's point is to swap that cache for email, Slack or shared docs, and to swap the training agents for always-on personal agents. The result is a worm path. Separately, OpenAI's own testing shows dots stopped correctly when permissions changed mid-task in **45 of 49** runs (about 92%), with a noted "tendency to overreach" (BankInfoSecurity).

**Why it matters for QCo:** Every agent we're piloting or considering reads shared channels: Team Bots, dots, @ChatGPT in Teams, and Muse. If one agent's output lands where another agent reads it as an instruction, a single bad input spreads. A 92% stop rate means about one run in twelve keeps going after permission is pulled. That's fine for drafts and not fine for anything near NetSuite.

**What's not being said:** No vendor has published a test for agents reading each other's output. The 45/49 figure is OpenAI grading itself.

**Hype:** Low. It's an argument from a respected cryptographer built on a real incident. **Sentiment:** Moderate, loud among security and developer audiences.

**Actionable:** Add an eval-hygiene v1.1 rule: **text written by another agent is data, never permission or instruction**. That covers posts in Slack and Teams channels, emails and shared files. It pairs with Tuesday's "permission only from a named human" rule. In the pilot, add one test where Bot A posts an instruction and Bot B must ignore it. Add this to the addendum; the scorecard stays locked. Treat 45/49 as the bar to beat: our stop-on-block test expects 100% on writes.

**Messaging Themes (light):** Always-on agents add a new way for attacks to spread. That's a reason for human gates, not for fear. Our pilot already keeps agents to drafts.

**Actionable:** Add Argon to the frontier lane of the matrix as "watch, not available to QCo." When it ships to paid API customers, include it in the prompt-injection test alongside Astra and Opus 5.5. No seat change.

**Messaging Themes:** Acknowledge that Google is releasing to defenders first. Stick to the facts: the gating is voluntary and cites government testing. The cyber substance is real. Pivot: QCo doesn't need frontier cyber models. We need fast patching and agents that are hard to inject.
