# Knowledge Systems

Working docs for QCo’s layered Source-of-Truth approach (humans + AI agents).

## Layout

| Folder | What goes here |
| --- | --- |
| `memos/` | Council-facing options memos and decision briefs |
| `research/` | Landscape packs and evidence appendices |
| `checklists/` | Operating gates (e.g. certified-slices minimums) |

## Conventions

- Prefer descriptive filenames: `QCo-<Topic>-<Type>.md`
- New workstreams get a sibling under `docs/` (same pattern: memos / research / checklists) when volume grows
- Certified slices only enter the agent path after the checklist gate
